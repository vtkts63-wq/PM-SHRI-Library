# PM SHRI Library APK build

यह ZIP Flutter project है। APK बनाने के लिए इसे GitHub repository में upload करें:

1. GitHub पर नया repository बनाएं और इस ZIP के अंदर `books_qr_library` folder की files upload करें (folder के अंदर की files repository के root में हों)।
2. Repository में Actions tab खोलें।
3. `Build Android APK` workflow चुनें और `Run workflow` दबाएं।
4. Build पूरा होने पर workflow run खोलें और Artifacts में `PM-SHRI-Library-APK` डाउनलोड करें।
5. डाउनलोड ZIP के अंदर `app-release.apk` मिलेगी। इसे Android फोन में install किया जा सकता है।

APK build cloud GitHub Actions पर होगा; इस ZIP में अभी compiled APK शामिल नहीं है।
